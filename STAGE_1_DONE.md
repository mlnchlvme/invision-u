# Этап 1 — Выполнено

## Что сделано

### 1. Разделение клиентов абитуриентов и приёмной комиссии
- Удалён `RoleBar.jsx` с переключателем ролей.
- Создан `Header.jsx` — шапка без переключения ролей, только логотип и кнопка выхода.
- Роль определяется из JWT-токена (`role` поле в ответе API). Абитуриент видит только свой кабинет, комиссия — только свой. Переключиться нельзя.
- `App.jsx` полностью переписан: роутинг через состояние `screen` (landing → auth → portal).

### 2. Единая страница Sign In / Sign Up
- `src/pages/Auth.jsx` — два таба: «Войти» и «Регистрация».
- Подключены `POST /api/auth/login` и `POST /api/auth/register`.
- Валидация полей, показ ошибок API, индикатор загрузки, показ/скрытие пароля.
- Анимированный вход через CSS (`slideUp`).

### 3. Лендинг-страница
- `src/pages/Landing.jsx` — публичная страница с описанием программы.
- Секции: Hero, Статистика, Возможности, D.R.I.V.E., Процесс, CTA, Footer.
- Адаптивная вёрстка.
- Кнопки ведут на страницу авторизации.

### 4. API-слой
- `src/api/client.js` — базовый fetch с Bearer-авторизацией.
- `src/api/auth.js`, `applications.js`, `questions.js`, `interview.js`, `admin.js` — все эндпоинты из спецификации.
- `src/context/AuthContext.jsx` — глобальное состояние: токен, роль, userId, fullName, appId; сохранение в `localStorage`.

### 5. API-интеграция во все компоненты
- `CandidateStatus` — загружает `GET /api/applications/{id}/detail`.
- `CandidateQuestions` — загружает вопросы с `GET /api/questions`, сохраняет через `PUT .../answers`.
- `CandidateInterview` — запускает интервью через `POST /api/interview/{id}/start`, отправляет ответы через `POST .../message`.
- `CandidateVideo` — получает видео-вопросы, сохраняет URL через `PUT .../video`.
- `CandidateProcessing` — получает статус через `GET /api/applications/{id}/status`.
- `CommDashboard` — загружает `GET /api/dashboard`, выносит решения через `POST .../decision`.
- `CommSettings` — сохраняет настройки через `PUT /api/settings`.

### 6. SVG-иконки вместо эмодзи
- `src/components/icons/index.jsx` — 27 SVG-компонентов в стиле Feather Icons.
- Все эмодзи в навигации, кнопках, статусах и заглушках заменены на SVG.
- `mockData.js` обновлён: навигационные иконки используют `iconKey` вместо строк с эмодзи.

### 7. Анимации
- `fadeIn`, `slideUp`, `pageEnter` — плавные переходы при загрузке страниц.
- `.skeleton` — shimmer-эффект для загрузки данных.
- `page-enter` класс — анимация смены раздела в Sidebar.
- Hover-анимации на карточках и кнопках.

- Полная документация изменений в `README.md`.
